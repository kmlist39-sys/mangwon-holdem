# 망원동 홀덤

안드로이드에서 혼자 즐기는 동네 홀덤 게임입니다. 망원동과 성산동에서는 데일리 토너먼트에 참가하고, 당산에서는 캐시 홀덤과 더블보드를 즐길 수 있습니다.

## 0.7.4 Android Studio 프로젝트

저장소 루트를 Android Studio에서 열면 됩니다. Android SDK 36을 설치한 뒤 Windows에서는 `gradlew.bat assembleDebug`, macOS·Linux에서는 `./gradlew assembleDebug`로 디버그 APK를 빌드할 수 있습니다. 실행에는 Android 8.0 이상이 필요합니다.

테이블 화면과 입력 처리는 `app/src/main/java`, 홀덤 규칙과 AI는 `app/src/main/assets/club.js`에 있습니다. 펍 배경·캐릭터·손 모션은 `app/src/main/assets`, 딜러 음성은 `app/src/main/assets/dealer-voice`에서 볼 수 있습니다.
